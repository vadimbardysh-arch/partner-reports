📅 План просування на 3 місяці

Поетапний план відновлення та зростання замовлень для Ваш Лаваш (Харків).

🔵 Місяць 1 — Липень 2026: Стабілізація та відновлення

Мета: зупинити падіння, повернути базовий потік замовлень, залучити нових клієнтів.

  • Smart Promos — знижка 10–15% для нових користувачів (Bolt покриває до 50%)
  • Smart Promos для неактивних — безкоштовна доставка для тих, хто не замовляв 14+ днів
  • Регулярна акція через Портал — 10% знижка на перше замовлення
  • Оновлення меню — перевірити фото, описи, виділити топ-страви
  • Участь у тематичній кампанії «Літній Фест» (якщо доступна)

Очікуваний результат: 85–100 замовлень/міс

🟢 Місяць 2 — Серпень 2026: Масштабування

Мета: наростити обсяги, побудувати впізнаваність бренду, збільшити базу клієнтів.

  • Sponsored Listings — запуск преміального розміщення
  • Smart Promos — продовження + розширення на churned users (не замовляли 21+ днів)
  • Літня тематична кампанія — сезонні позиції, знижки на обідне меню
  • A/B тестування знижок: % знижка vs безкоштовна доставка

Очікуваний результат: 110–130 замовлень/міс

🟩 Місяць 3 — Вересень 2026: Оптимізація та утримання

Мета: закріпити результати, оптимізувати витрати, зосередитись на retention.

  • Sponsored Listings — продовження (оцінка ROAS, коригування)
  • Smart Promos — фокус на returning users (не замовляли 14+ днів)
  • Рекламний банер — осінній сезон «Back to School» / Вересень
  • Аналіз ефективності — звіт ROAS по всіх інструментах
  • Планування зимового сезону — підготовка до нових тематичних кампаній

Очікуваний результат: 120–150 замовлень/міс, стабільна база лояльних клієнтів
